# Выбор AI-модели и стоимость генерации

Документ закрывает требование ТЗ п.5: «выбор AI-модели на усмотрение разработчика
(готовый API или open-source), с обоснованием и оценкой стоимости одной генерации».

## Что выбрано

**FASHN AI, модель `tryon-v1.6`** — специализированный API виртуальной примерки.

Подключение: `POST https://api.fashn.ai/v1/run` → получаем `id` → опрашиваем
`GET https://api.fashn.ai/v1/run/{id}` до статуса `completed`.
Реализация: [`lib/tryon/fashn.ts`](../lib/tryon/fashn.ts).

## Почему именно он

| Критерий | FASHN (выбран) | Replicate / IDM-VTON (open-source) | Универсальные image-модели (Gemini и др.) |
|---|---|---|---|
| Качество на одежде | Модель обучена только на примерке: держит крой, логотипы, длину рукава | Заметно слабее на сложных позах, часто «плывут» руки | Непредсказуемо: может перерисовать лицо или фигуру |
| Скорость | 5–17 с | 15–60 с (плюс «холодный старт» до 1–2 мин) | 10–20 с |
| Цена за генерацию | Фиксированная, предсказуемая | Плата за секунды GPU — счёт зависит от нагрузки | Фиксированная |
| Поддержка категорий | `tops` / `bottoms` / `one-pieces` / `auto` | Обычно только верх | Нет, только текстовый промпт |
| Запуск | Ключ API, ничего не разворачиваем | Нужен свой GPU или сторонний хостинг | Ключ API |

Главный аргумент: у заказчика MVP, а не исследовательский проект. Специализированная
модель даёт лучший результат «из коробки» без возни с GPU, а цена за картинку
фиксирована — её можно заранее посчитать и заложить в бюджет.

Open-source (IDM-VTON, OOTDiffusion) остаётся запасным вариантом, если объём вырастет
настолько, что свой GPU станет дешевле API. Из-за абстракции провайдера
([`lib/tryon/types.ts`](../lib/tryon/types.ts)) переход = один новый файл, интерфейс
приложения не меняется.

## Стоимость

По открытому прайсу FASHN на сентябрь 2026:

- **$0.075 за одну успешную генерацию** (on-demand, без обязательств);
- **менее $0.04** за генерацию на объёмных тарифах с предоплатой;
- **неудачная генерация не тарифицируется** — платим только за выданную картинку.

Прогноз расходов на API (по курсу ~80 ₽/$, уточнить на момент запуска):

| Примерок в месяц | On-demand ($0.075) | Объёмный тариф (~$0.04) |
|---|---|---|
| 100 | $7.5 (~600 ₽) | — |
| 1 000 | $75 (~6 000 ₽) | $40 (~3 200 ₽) |
| 10 000 | $750 (~60 000 ₽) | $400 (~32 000 ₽) |

Хостинг на Vercel: бесплатный тариф для демо и приёмки, ~$20/мес при росте нагрузки.

> Цены проверены по публичному прайсу FASHN в сентябре 2026 и могут измениться —
> перед подписанием сверьте с https://fashn.ai/pricing.

## Как защищён бюджет

Сайт публичный и без регистрации, поэтому ключ защищён на двух уровнях:

1. Ключ хранится только в переменных окружения сервера и никогда не попадает в браузер —
   все вызовы идут через наш роут [`app/api/tryon/route.ts`](../app/api/tryon/route.ts).
2. Ограничение частоты запросов по IP — [`lib/rate-limit.ts`](../lib/rate-limit.ts),
   по умолчанию 6 запросов в минуту (настраивается через `RATE_LIMIT_MAX`).

Для публичного запуска с рекламным трафиком дополнительно рекомендуется включить
rate limit на уровне платформы (Vercel WAF) — счётчик в памяти процесса не защищает
от распределённой атаки.

## Ограничения качества (важно проговорить с заказчиком)

AI-примерка 2026 года работает хорошо, но не идеально. Стабильно хуже результат на:

- сильно неудачных позах (руки скрещены, человек боком, обрезана часть тела);
- очень свободной одежде и многослойных образах;
- мелких принтах и надписях — текст на футболке может «поплыть».

Поэтому в интерфейсе (внизу страницы) стоит честная оговорка, что результат —
приблизительная визуализация, а не точное фото вещи на клиенте.

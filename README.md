# Виртуальная примерочная

Веб-приложение: пользователь загружает своё фото и выбирает вещь — AI показывает,
как она будет выглядеть на нём. Результат можно скачать.

- Загрузка фото человека и одежды
- Каталог из 15 вещей с фильтром по категориям + загрузка своей вещи
- Генерация примерки через AI, индикатор загрузки со счётчиком времени
- Сравнение «до / после» ползунком, скачивание результата
- Три языка: русский, английский, казахский
- Адаптивный интерфейс: работает на телефоне и на компьютере

---

## Быстрый запуск (5 минут)

Нужен установленный [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install          # установить зависимости
npm run dev          # запустить сайт
```

Откройте http://localhost:3000 — сайт работает.

Без ключа API сайт запускается в **демо-режиме**: вместо настоящей примерки
возвращается картинка-заглушка с водяным знаком. Так можно проверить весь
интерфейс, ничего не оплачивая.

## Подключение AI (настоящая примерка)

1. Зарегистрируйтесь на https://fashn.ai и привяжите карту.
2. В личном кабинете откройте **Settings → API** и создайте ключ.
3. Скопируйте файл `.env.example` в `.env.local` и вставьте ключ:

```bash
cp .env.example .env.local
```

```
FASHN_API_KEY=ваш_ключ_отсюда
```

4. Перезапустите `npm run dev`. Плашка «Демо-режим» исчезнет — примерка настоящая.

Стоимость: **$0.075 за одну генерацию**, неудачные не тарифицируются.
Подробный расчёт и обоснование выбора модели — в [docs/model-choice.md](docs/model-choice.md).

## Деплой на Vercel

1. Залейте репозиторий на GitHub.
2. На https://vercel.com нажмите **Add New → Project**, выберите репозиторий.
3. В **Environment Variables** добавьте `FASHN_API_KEY` со значением ключа.
4. **Deploy**. Через пару минут получите рабочую ссылку.

Отдельная настройка не нужна — Vercel сам определит Next.js.
Дальше каждый `git push` обновляет сайт автоматически.

## Что происходит с фото (требование ТЗ по приватности)

Фотографии пользователей **нигде не сохраняются**:

- фото не записываются ни на диск сервера, ни в базу данных, ни в логи;
- фото живут только в памяти во время одного запроса и исчезают после ответа;
- в браузере фото хранится до перезагрузки страницы и никуда больше не пишется
  (ни в localStorage, ни в cookies);
- ответ отдаётся с заголовком `Cache-Control: no-store`, чтобы копия не осела в кэше.

Это не обещание на словах: `tests/privacy.test.ts` подменяет файловые операции
и журнал во время реального запроса и падает, если фото туда попадёт.

Единственное исключение, о котором нужно знать заказчику: во время генерации фото
передаётся провайдеру модели (FASHN) — без этого примерка невозможна. Их политика
хранения указана в их документации; если требуется «фото не покидают наш контур»,
нужна self-hosted модель (см. docs/model-choice.md, раздел про open-source).

## Как заменить каталог на реальные вещи

Сейчас в каталоге лежат фотографии с Unsplash (свободная лицензия) — они годятся
для демонстрации, но перед запуском их нужно заменить на снимки товаров заказчика.
Источники текущих фото перечислены в [`public/catalog/CREDITS.md`](public/catalog/CREDITS.md).

1. Положите фото в `public/catalog/` (JPEG или PNG, вещь целиком на однотонном фоне,
   как в интернет-магазине; фото на модели тоже подходит).
2. Впишите вещь в список в [`lib/catalog.ts`](lib/catalog.ts):

```ts
{ id: "tee-white", category: "tops", file: "tee-white.jpg" },
```

- `id` — любой уникальный текст латиницей;
- `category` — `tops` (верх), `bottoms` (низ) или `one-pieces` (платья);
- `file` — имя файла в `public/catalog/`.

3. Добавьте название вещи на каждом языке — в файлах `lib/i18n/dictionaries/ru.ts`,
   `en.ts` и `kk.ts`, в разделе `items`:

```ts
"tee-white": "Белая футболка",
```

Названия лежат в словарях, а не в каталоге, чтобы каталог переводился вместе
с остальным интерфейсом.

## Языки

Сайт работает на русском, английском и казахском. Адрес включает язык:
`/ru`, `/en`, `/kk`. При заходе на корень сайта язык определяется по настройкам
браузера, а выбор пользователя запоминается в cookie.

**Как добавить ещё один язык:**

1. Добавьте код языка в `LOCALES` и `LOCALE_META` в [`lib/i18n/config.ts`](lib/i18n/config.ts).
2. Скопируйте `lib/i18n/dictionaries/ru.ts` в файл нового языка и переведите строки.
3. Зарегистрируйте словарь в [`lib/i18n/index.ts`](lib/i18n/index.ts).

Больше ничего менять не нужно: TypeScript сам укажет, если в новом словаре
не хватает какой-то строки. Тексты ошибок тоже переводятся — сервер отдаёт
код ошибки, а не готовую фразу.

> Казахский перевод сделан разработчиком и не проверялся носителем языка —
> перед публичным запуском стоит показать его казахоязычному редактору.

## Тесты

135 автотестов, запускаются за несколько секунд: `npm test`.

Что они покрывают:

| Файл | Что проверяет |
|---|---|
| `tests/fashn.test.ts` | Работу с API модели: запрос, опрос статуса, разбор ошибок. Вместо настоящего сервиса поднимается его заглушка, поэтому платный путь проверен без расходов |
| `tests/api-tryon.test.ts` | Endpoint примерки целиком: успех, все виды отказов, ограничение частоты |
| `tests/api-download.test.ts` | Скачивание результата и защиту от подстановки чужого адреса |
| `tests/privacy.test.ts` | Что фото не попадает ни на диск, ни в логи — обещание из ТЗ, проверенное кодом |
| `tests/validation.test.ts` | Проверку загружаемых файлов до обращения к платной модели |
| `tests/rate-limit.test.ts` | Защиту бюджета от накрутки запросов |
| `tests/i18n.test.ts` | Что во всех языках одинаковый набор строк, без пустых и потерянных подстановок |
| `tests/catalog.test.ts` | Что у каждой вещи есть файл на диске и название на каждом языке |

Те же проверки выполняются автоматически при каждом push — [.github/workflows/ci.yml](.github/workflows/ci.yml).

## Смена AI-модели

Приложение не привязано к одному провайдеру. Чтобы перейти на другую модель
(Replicate, fal.ai, своя на GPU), достаточно добавить файл рядом с
[`lib/tryon/fashn.ts`](lib/tryon/fashn.ts), реализовав интерфейс `TryOnProvider`
из [`lib/tryon/types.ts`](lib/tryon/types.ts), и подключить его в
[`lib/tryon/index.ts`](lib/tryon/index.ts). Интерфейс сайта менять не нужно.

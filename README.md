# Виртуальная примерочная

Веб-приложение: пользователь загружает своё фото и выбирает вещь — AI показывает,
как она будет выглядеть на нём. Результат можно скачать.

- Загрузка фото человека и одежды
- Каталог из 14 вещей + загрузка своей вещи
- Генерация примерки через AI, индикатор загрузки
- Скачивание результата
- Адаптивный интерфейс: работает на телефоне и на компьютере

---

## Быстрый запуск (5 минут)

Нужен установленный [Node.js](https://nodejs.org) версии 20 или новее.

```bash
npm install          # установить зависимости
npm run dev          # запустить сайт
```

Откройте http://localhost:3000 — сайт работает.

Без ключа API сайт запускается в **демо-режиме**: вместо настоящей примерки
возвращается картинка-заглушка с водяным знаком. Так можно проверить весь
интерфейс, ничего не оплачивая.

## Подключение AI (настоящая примерка)

1. Зарегистрируйтесь на https://fashn.ai и привяжите карту.
2. В личном кабинете откройте **Settings → API** и создайте ключ.
3. Скопируйте файл `.env.example` в `.env.local` и вставьте ключ:

```bash
cp .env.example .env.local
```

```
FASHN_API_KEY=ваш_ключ_отсюда
```

4. Перезапустите `npm run dev`. Плашка «Демо-режим» исчезнет — примерка настоящая.

Стоимость: **$0.075 за одну генерацию**, неудачные не тарифицируются.
Подробный расчёт и обоснование выбора модели — в [docs/model-choice.md](docs/model-choice.md).

## Деплой на Vercel

1. Залейте репозиторий на GitHub.
2. На https://vercel.com нажмите **Add New → Project**, выберите репозиторий.
3. В **Environment Variables** добавьте `FASHN_API_KEY` со значением ключа.
4. **Deploy**. Через пару минут получите рабочую ссылку.

Отдельная настройка не нужна — Vercel сам определит Next.js.
Дальше каждый `git push` обновляет сайт автоматически.

## Что происходит с фото (требование ТЗ по приватности)

Фотографии пользователей **нигде не сохраняются**:

- фото не записываются ни на диск сервера, ни в базу данных, ни в логи;
- фото живут только в памяти во время одного запроса и исчезают после ответа;
- в браузере фото хранится до перезагрузки страницы и никуда больше не пишется
  (ни в localStorage, ни в cookies);
- ответ отдаётся с заголовком `Cache-Control: no-store`, чтобы копия не осела в кэше.

Единственное исключение, о котором нужно знать заказчику: во время генерации фото
передаётся провайдеру модели (FASHN) — без этого примерка невозможна. Их политика
хранения указана в их документации; если требуется «фото не покидают наш контур»,
нужна self-hosted модель (см. docs/model-choice.md, раздел про open-source).

## Как заменить каталог на реальные вещи

Сейчас в каталоге лежат **схематичные заглушки**, сгенерированные скриптом.
Для реальных результатов примерки нужны настоящие фото вещей.

1. Положите фото в `public/catalog/` (JPEG или PNG, вещь целиком на однотонном фоне,
   как в интернет-магазине).
2. Откройте [`lib/catalog.ts`](lib/catalog.ts) и впишите вещи в список:

```ts
{ id: "tee-white", name: "Белая футболка", category: "tops", file: "tee-white.png" },
```

- `id` — любой уникальный текст латиницей;
- `name` — то, что видит пользователь;
- `category` — `tops` (верх), `bottoms` (низ) или `one-pieces` (платья);
- `file` — имя файла в `public/catalog/`.

Заглушки можно пересоздать командой:

```bash
node scripts/generate-catalog-placeholders.mjs
```

## Структура проекта

```
app/
  page.tsx                 главная страница
  components/              интерфейс: загрузка фото, каталог, результат
  api/tryon/route.ts       приём запроса на примерку, вызов AI
  api/download/route.ts    скачивание результата файлом
lib/
  catalog.ts               список вещей каталога
  catalog.server.ts        чтение картинок каталога с диска
  tryon/                   работа с AI-моделью
    types.ts               общий интерфейс провайдера
    fashn.ts               провайдер FASHN AI
    demo.ts                заглушка для работы без ключа
  validation.ts            проверка загруженных файлов
  rate-limit.ts            защита от накрутки запросов
  client/image.ts          сжатие фото в браузере перед отправкой
docs/model-choice.md       обоснование выбора модели и расчёт стоимости
scripts/                   генератор картинок-заглушек каталога
```

## Смена AI-модели

Приложение не привязано к одному провайдеру. Чтобы перейти на другую модель
(Replicate, fal.ai, своя на GPU), достаточно добавить файл рядом с
[`lib/tryon/fashn.ts`](lib/tryon/fashn.ts), реализовав интерфейс `TryOnProvider`
из [`lib/tryon/types.ts`](lib/tryon/types.ts), и подключить его в
[`lib/tryon/index.ts`](lib/tryon/index.ts). Интерфейс сайта менять не нужно.
